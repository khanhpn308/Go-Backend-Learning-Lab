# Learning State

Đây là hồ sơ tiến độ kỹ thuật, dùng để tiếp tục học giữa các New Chat.

- [Current Session](current-session.md): điểm bắt đầu và bước tiếp theo.
- [Skill Map](skill-map.md): kỹ năng, level và evidence.
- [Progress](progress.md): lessons/practices và kết quả.
- [Misconceptions](misconceptions.md): lỗi tư duy được quan sát.
- [Review Queue](review-queue.md): kỹ năng đến hạn ôn.

Khi lưu trạng thái, cập nhật các file liên quan đồng nhất; current-session.md trỏ tới bài/practice và bước kế tiếp. Ghi ngày, source commit, Lab path/commit nếu có, mức hỗ trợ, evidence và test result thực tế. Không thay đổi level nếu thiếu bằng chứng độc lập.

Không lưu secrets, thông tin riêng tư hoặc dữ liệu thật nhạy cảm; repo công khai. Chỉ ghi trạng thái GitHub khi người học yêu cầu. N/A nghĩa là chưa đánh giá, không phải 0.

Khởi tạo: chưa có kết quả diagnostic hoặc practice. Không giả định trình độ.
